# Конструктор эффектов для TikTok-игр — план / ТЗ (черновик, 2026-10-27)

Статус: **обсуждение**, реализация не начата. Парный документ: [`battle.md`](battle.md) (командная битва), общий порядок работ — в конце этого файла.

## Задача
Стример в любой нашей TikTok-игре (Угадай слово, Анимация, будущая битва) загружает свои анимации и привязывает их к подаркам и действиям зрителей — по образу наших шариков и самолётов (`stream-engine/app/web/common/balloons.js`, `plane.js`), которые сейчас привязаны только к лайкам. К эффекту привязываются аватар и/или имя зрителя и звук из библиотеки.

## Ключевая идея: движение наше, картинка стримера
Готовый ролик, где всё уже летит, нельзя связать с аватаром — неизвестно, где в кадре объект. Поэтому, как с самолётом:
- **Спрайт** — стример загружает объект, анимированный «на месте»; траекторию выбирает из наших шаблонов, аватар и имя едут вместе со спрайтом.
- **Клип** — полноэкранный ролик или ролик в зоне экрана; точку аватара/имени стример один раз отмечает мышкой.

## Форматы
- **WebM с альфой (VP9)** — основной; TT Studio на Chromium его играет.
- **Анимированный WebP / APNG / GIF** — самые доступные.
- **Lottie (JSON)** — лёгкий вектор, библиотека LottieFiles. Только сборка `lottie_light` (без expressions, чужой JS не исполняется).
- **SVG запрещён** (XSS).
- Лимиты: 5 МБ на файл, до 10 с, 100 МБ на стримера. Проверка на сервере через `ffprobe`, без перекодирования в MVP.

## Траектории (шаблоны)
Пролёт через экран (как самолёт), всплытие снизу (как шарики), «дождь» из N штук, выезд из угла, «удар» в центр, клип на весь экран / в зону.
Параметры: размер, скорость, количество, зеркалить, плашка с именем.

## Триггеры
- **Подарок**: любой подарок; подарок «X» (привязанный к эффекту); подарок от N монет. Комбо — повтор или увеличение эффекта.
- **Лайки**: N лайков от одного зрителя; каждые N лайков в сумме.
- **Действия**: подписка, репост, вход в эфир.
- **Команда в комментарии** (`!ракета`) с кулдауном.
- **События игры**: каждая игра публикует именованные события (угадал, раунд выигран, база уничтожена…) — на них тоже вешаются эффекты. Это делает конструктор общим для всех игр.

## Аватар, имя, звук, очередь
- Аватар — кружок у точки привязки, имя — плашкой.
- Звук из библиотеки или свой; громкость на эффект.
- Очередь: не больше K одновременно, дорогие подарки вне очереди, кулдаун на эффект и на зрителя.

## Библиотека звуков
- **Kenney.nl** (CC0) — основа: игровые паки.
- **Freesound** — только CC0 (CC-BY требует подписи — не берём).
- **Sonniss GDC bundle** — качество высокое, но лицензия запрещает раздавать как библиотеку; в наших эффектах можно, давать стримеру скачивать — серая зона.
- **ElevenLabs Sound Effects** — генерация недостающего; коммерческая лицензия только на платном тарифе (~$5–22/мес).
- **Свои звуки** стримера — под его ответственность (галочка при загрузке).

Отбор ~150 звуков по категориям, громкость `ffmpeg loudnorm` до −16 LUFS. Прослушивание и отбраковка — владелец (на слух Claude не проверяет).

## Архитектура
- **Laravel, платформенный сервис** (правило 3 в `CLAUDE.md`): таблицы `effect_assets`, `effect_rules`; файлы через Spatie media на диске `aws-dev`; вкладка «Эффекты» в настройках комнаты — загрузка, превью, траектория, триггер, «Применить сейчас»; 4 языка.
- **Engine**: `GiftRules` и `_gift_animations` из `stream-engine/app/hub.py` обобщаются в `stream-engine/app/reactions/effects.py` — слушает все события (подарок, лайк, подписка, репост, комментарий, события игры) и шлёт в ленту `{type:'effect', …}`. Правила и список файлов берёт у Laravel по `/internal`.
- **Фронт**: один скрипт `stream-engine/app/web/common/effects.js` во всех оверлеях; шарики и самолёт становятся встроенными пресетами той же системы (без двух параллельных механизмов).

## Трудозатраты (MVP), прикидка
| Этап | Сессий |
|---|---|
| Шина событий + `effects.py` + перенос подарков/шариков/самолёта в пресеты, тесты | 1,5–2 |
| `effects.js`: форматы, траектории, аватар/имя, очередь | 1,5–2 |
| Laravel: модели, загрузка с проверкой, вкладка «Эффекты», 4 языка | 1,5–2 |
| Библиотека звуков + прослушивание владельцем | 0,5–1 |
| Выкатка, живой эфир, правки | 1 |
| **Итого** | **≈ 6–8** |

Позже (+2–3 сессии): редактор точки привязки аватара, движущейся по кадрам клипа.
Расходы на работу: диск `aws-dev`, трафик — разовая загрузка файлов в оверлей; платный только ElevenLabs, если решим генерировать.

Сессия ≈ вечер работы; цифры по аналогии с «Угадай слово» и `ai-mailbox`, не замер. Фактический расход мерить `tiktok-clips/tools/usage-report.js`.
