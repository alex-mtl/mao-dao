# Командная битва на 2–6 команд («Крепости») — план / ТЗ (черновик, 2026-10-27)

Статус: **обсуждение**, реализация не начата. Прототип (один файл, Canvas 2D, боты + имитация чата): [`stream-engine/app/web/demo/battle-arena.html`](../../stream-engine/app/web/demo/battle-arena.html) — открывается прямо из файла. Заменяет пробную игру «красные против жёлтых» (`stream-engine/app/games/battle/`). Зависит от конструктора эффектов: [`effects.md`](effects.md).

## Концепция
Вертикальный экран 9:16, в центре арена.
- 2 команды — друг против друга, сверху и снизу.
- 3–6 команд — базы по кругу.

У каждой команды крепость с запасом прочности. Зрители не жмут кнопки, а пополняют войско своей команды; юниты сами маршируют и дерутся. Залипательность — сотни бойцов с именами зрителей на экране.

## Механика
- **Вступление**: комментарий с номером, эмодзи цвета или названием команды. Без выбора — в самую маленькую команду.
- **Комментарий** = боец с именем зрителя, не чаще раза в N секунд.
- **Лайки** заряжают шкалу команды; полная шкала — залп.
- **Подписка** — щит на базу. **Репост** — подкрепление (5 бойцов).
- **Подарки** по ценовым ступеням (настраиваются через конструктор эффектов):
  - мелкий — юнит-герой с аватаром дарителя;
  - средний — осадная машина;
  - крупный — суперудар («метеорит») по выбранной команде.
- **Цель**: `!атака 3`; без команды бьют лидера — встроенный камбэк. Слабые команды получают небольшой бонус.
- **Выбывшие** не уходят: их комментарии — «призраки», кусающие лидера.
- **Раунд**: 3–5 минут или до последней уцелевшей базы.
- **Статистика**: у главного дарителя команды корона капитана; отдельно самый результативный боец.
- **Диктор** через `AudioKit.say`, как в «Угадай слово» («Синие потеряли крепость!»).

## Техника
- **Engine (сервер)** считает экономику: прочность баз, численность, урон по формуле раз в 0,5 с, события спавна с seed — картинка одинакова в любом окне. Восстановление после перезапуска, как в остальных играх.
- **Оверлей** только рисует бойцов по событиям; позиции сотен юнитов по WebSocket не передаются.
- **Отрисовка**: PixiJS (WebGL) — 300+ спрайтов в 60 fps внутри TT Studio; DOM/CSS не тянет.
- **Графика**: одни спрайты, перекрашенные в цвет команды (6 команд ≠ ×6 арта); Kenney (CC0) или генерация; звуки — из библиотеки конструктора.
- **Симулятор** в `stream-engine/app/web/debug`: 200 ботов с регулируемой активностью — для баланса до живого эфира.
