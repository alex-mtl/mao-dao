# Словарь определений + эмбеддинги Sber (слово + определение)

Архив подготовлен 2026-11-02 (Дружок) для Клоди: задеплоить новый ранкер и запушить исходники в репозиторий mao-dao.

## Что это и зачем

Подсказки игры «Угадай слово» строятся на геометрии эмбеддингов: ранг догадки против секрета.
Старая матрица кодировала голые слова — для многозначных и редких слов соседи получались
мусорными (вена → балка, магистраль; обо → сойот, идо). Новая матрица кодирует слово ВМЕСТЕ
с его словарным определением: входная строка — `слово — определение`. Проверка на 9 словах
(вена, плат, параллелограмм, чет, гордон, обо, славян, наполеон, дозорный) показала заметно
лучших соседей почти везде. Детали проверки — в разделе «Проверка» ниже.

## Состав архива

| Файл | Что это |
|---|---|
| `definitions-pool-5784.jsonl` | Определения слов пула секретов: 5 784 строки, `{"word", "definition", "flag"?}` |
| `definitions-rest-32576.jsonl` | Определения остальных слов словаря: 32 576 строк, тот же формат |
| `definitions-all-38322.jsonl` | Слияние пула и остатка в порядке словаря, БЕЗ 38 удаляемых слов: 38 322 строки |
| `definitions-run-37218.jsonl` | Рабочий словарь прогона: 37 218 строк, БЕЗ всех 1 142 неуверенных, порядок словаря |
| `uncertain-words-1142.jsonl` | Все 1 142 слова с флагом uncertain + их определения + источник (pool/rest). НЕ для деплоя, на разбор владельцем |
| `FLAGS-pool.md` | 38 сомнительных слов пула с определениями |
| `FLAGS-rest.md` | 1 104 сомнительных слова остатка с определениями, по чанкам |
| `def-sbert-matrix-fp16.npy` | Матрица эмбеддингов: 37 218 × 1024, float16, строки L2-нормированы |
| `def-sbert-words.txt` | Слова строк матрицы, по одному на строку, порядок = порядок строк |

Формат определений: одно предложение, 4–20 слов, стиль словарной статьи, строчная буква,
без точки в конце, без «это», родовое слово первым, без самого определяемого слова и
однокоренных слов в определении. Pluralia tantum (сутки, ножницы, деньги, весы, часы и т.п.)
определены во множественном числе.

## Как строились словари

- Исходный словарь: 38 360 слов (vocab из живого `meta.json`/assets, порядок — порядок словаря).
- Пул: 5 784 слова. Остаток: 32 576 слов (38 360 − 5 784), 94 чанка по 350 слов.
- Определения писали агенты-работники из собственных языковых знаний, веб-поиск — только
  по сомнительным словам (доля поисков <15% на чанк). Каждый чанк проверен скриптом:
  точное покрытие, валидный JSON, уникальность, непустые определения.
- Аудит множественного числа по пулу: все 108 pluralia tantum определены во множественном числе.

## Решения владельца (зафиксированы в записках 2026-11-02)

1. 38 слов пула с флагом uncertain УДАЛЯЮТСЯ отовсюду: из обоих словарей определений,
   из пула секретов и из словаря, относительно которого строится индекс. Список:
   авторские, борн, бреннер, взрывной, внука, вод, вольный, вольта, выпал, диас, казимир,
   коваль, колчак, кондратий, конный, крон, кузьминки, лет, летие, линкольн, люка, майна,
   марго, мирон, молока, мура, напрокат, одер, планет, полом, роуд, скал, снимка, стрип,
   торо, харт, штейн, юнг. В `definitions-all-38322.jsonl` их уже нет.
2. ВСЕ 1 142 слова с флагом uncertain (38 пула + 1 104 остатка) убраны из рабочего словаря
   прогона, но СОХРАНЕНЫ в `uncertain-words-1142.jsonl` — владелец будет их разбирать
   («много вполне нормальных слов»). Удаление их из живого словаря/пула НЕ решено —
   только из словаря прогона.

## Прогон (Kaggle GPU, 2026-11-02)

- Модель: `ai-forever/sbert_large_mt_nlu_ru` (та же, что сейчас в проде, через Lambda).
- Вход: `слово — определение` (em-dash U+2014 с пробелами), файл `definitions-run-37218.jsonl`.
- Параметры: batch 512, `normalize_embeddings=True`, сохранение в float16.
  Паттерн ядер — как в октябрьских прогонах (см. `kaggle-kernel-full` в рабочем каталоге).
- Проверка матрицы на VM: shape (37218, 1024), dtype float16, NaN нет, нормы строк
  1.0000 (min 0.9999, max 1.0001), порядок слов совпадает со входным файлом.
- Локально модель НЕ запускалась (правило: модели только на Kaggle GPU).

## Проверка (сравнение соседей: старая матрица голых слов vs новая)

- вена: артерия 2 (было 2), аорта 3 (было 16), капилляр 5 (было 375), кровь 10 (было 1040);
  смысл «город» ушёл на 32 934 место. Топ-10 стал чисто анатомическим.
- плат: было плата/кошель/мел → стало платок/шаль/полотнище.
- параллелограмм: было эллипсис/синхротрон → стало ромбоэдр/прямоугольник/треугольник.
- чет: нечет .88, четность, нечетность. гордон: породы собак (корги, доберман, сеттер).
- обо: пагода, дагоба, менгир, валун — верно. славян, дозорный: чище и с более высокими
  косинусами, чем раньше.
- ОГОВОРКА — наполеон: определение зафиксировано как «торт», соседи стали сплошь
  кондитерскими, смысл «император» пропал. Это цена одного зафиксированного смысла
  для многозначных слов; вопрос полисемии открыт (см. ниже).

## Что сделать Клоди

1. РЕПО: запушить словари (`definitions-run-37218.jsonl` + полные словари),
   список слов и скрипт сборки/загрузки. Матрицу 76 МБ в git НЕ коммитить —
   хранить в S3/хранилище Lambda, в репо только ссылку/скрипт получения.
2. ДЕПЛОЙ (ранкер Lambda): новая матрица покрывает 37 218 слов, а не 38 360.
   1 142 слова (список — `uncertain-words-1142.jsonl`) строк НЕ имеют: догадки и
   секреты на эти слова ранкер обработать не сможет. Нужен либо fallback (старая
   матрица для этих слов), либо ограничение угадываемого словаря, либо их
   докодирование позже — РЕШЕНИЕ ЗА ВЛАДЕЛЬЦЕМ, молча не деплоить.
3. ЖИВОЙ ПУЛ/СЛОВАРЬ: 38 слов из решения №1 удалить из `secret_nouns.txt`/`meta.json`
   и из словаря при пересборке ассетов (строки словаря совпадают со строками матрицы;
   естественный момент — эта пересборка). Рестарт `guessword-engine` — ТОЛЬКО не
   в середине раунда (правило владельца).
4. Поведение подсказок не меняется: полосы hint bands те же, AUTO_HINT=0 (автоподсказка
   выключена владельцем 2026-10-25). Меняется только геометрия ранжирования.

## Открытые вопросы (не решать за владельца)

- Разбор 1 142 неуверенных слов: какие вернуть (с исправленными определениями),
  какие удалить из словаря/пула окончательно.
- Полисемия: один смысл на слово (как сейчас) vs несколько смыслов / гибрид
  (голое слово + определение). Для этого прогона владелец выбрал чистые определения.
- Звуковое сходство: владелец в основном не согласен, что векторы определений
  его убивают, — проверить на бенчмарке синонимов при следующем сравнении.
