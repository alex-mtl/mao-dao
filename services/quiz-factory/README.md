# quiz-factory — генератор вопросов для викторины

Вопросы с 4 вариантами ответа из открытых данных (Wikidata, CC0). Модель на бесплатном GPU Kaggle только
переписывает формулировку и проверяет вопрос, но **не придумывает фактов**. Пока только русский язык и география.

```
build-geo.mjs   Wikidata SPARQL -> data/geo-drafts.json   (факты, шаблон вопроса, верный ответ, пул из ≤10 неверных)
kaggle.mjs      push: kaggle/polish.py на GPU Kaggle; wait: забрать data/kaggle/quiz-<run>.json
finalize.mjs    черновики + результат Kaggle -> data/geo-final.json и отчёт: что выброшено и почему
import.mjs      data/geo-final.json -> mao-dao.com, POST /internal/quizzes/import (квизы с тегом geography)
```

```bash
node build-geo.mjs --per-type=17                       # ~1 мин (запросы кешируются в data/cache)
node kaggle.mjs push data/geo-drafts.json              # печатает run id
node kaggle.mjs wait <run id>                          # раз в минуту проверяет; ~10-15 мин
node finalize.mjs data/geo-drafts.json data/kaggle/quiz-<run>.json
node import.mjs data/geo-final.json --dry-run
node import.mjs data/geo-final.json                    # секрет: ~/.mao-dao/quiz-import-secret
```

## Правила качества (сомнительное выбрасывается)

- У темы и у ответа есть статья в русской Википедии и русская метка; ответ не длиннее 32 символов (лимит платформы).
- У свойства ровно **одно** значение лучшего ранга: спорные границы, две столицы, разные высоты — мимо.
- Страны — только действующие суверенные государства.
- Неправильные ответы — того же рода (другая столица, другая страна того же континента) и **гарантированно неверны**:
  для гор соседние страны в пул не попадают (вершина на границе); для рек не предлагаются водоёмы, частью которых
  является устье (Бенгальский залив ⊂ Индийский океан), и океаны, если ответ — не океан; высоты не выше 8848 м.
- Вопрос не содержит ответа. Модель (Qwen2.5-7B) отвечает на готовый вопрос вслепую. Если её ответ не совпал
  с Wikidata, вопрос выбрасывается: так отсеиваются плохо сформулированные и неоднозначные вопросы.

## Неправильные ответы на старте раунда

В датасете у каждого вопроса есть **пул** неправильных ответов (до 10), а не ровно три. В mao-dao сейчас импортируется
верный ответ + 3 из пула (редактор квизов требует ровно 4). Следующий шаг — хранить пул на платформе и выбирать
3 случайных в начале раунда, как индексы в «Угадай слово». Это мгновенно, бесплатно и всегда верно. Микро-LLM в лямбде
нужна только вопросам без пула (свободным, не из Wikidata). Такой вариант надо проверять, потому что модель легко
выдаст «неправильный» ответ, который на самом деле тоже верен.
