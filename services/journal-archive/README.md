# journal-archive

Архив системного журнала движка игры (`guessword-engine` на aws-dev) в Cloudflare R2, бакет `stream-logs`.
Журнал — единственная полная история событий всех комнат (победы, самолёты, шарики, торты, ручные запуски `[manual]`, лайки, чат) с 21.10.2026; journald со временем удаляет старое, поэтому выгружаем.

- Объект: `guessword-engine/YYYY/YYYY-MM-DD.log.xz` — весь журнал за сутки UTC (`journalctl -o short-iso`), xz -9, ~2,3 МБ/сутки (29.10.2026: 36,9 МБ текста).
- Скрипт: `journal-to-r2.sh [YYYY-MM-DD ...]`, без аргументов — вчерашний день. Журнал только читает.
- На сервере: `/home/ubuntu/bin/journal-to-r2.sh`, cron пользователя ubuntu `30 0 * * *`, лог `~/journal-to-r2.log`.
- Ключи: `~/.config/r2-stream-logs.env` (токен только на этот бакет, чтение/запись), в git не кладём.
- Клиент R2 — `r2.py` (stdlib; curl 7.81 на сервере подписывает SigV4 для R2 неверно): `set -a; . ~/.config/r2-stream-logs.env; python3 ~/bin/r2.py list guessword-engine/`, скачать день — `python3 ~/bin/r2.py get guessword-engine/2026/2026-10-29.log.xz day.log.xz`.
- Выгружено 30.10.2026: 21–29.10 (6,2 МБ).

## Логи эфиров и аватарки — `lives-to-r2.sh`
- `rooms/<комната>/lives/<файл>.jsonl` → `lives/<комната>/<файл>.jsonl.xz` (только файлы, не менявшиеся 60 мин — эфир закончился; продолженный эфир перезаливается по новому размеру).
- `avatars/<uid>.<ext>` → `avatars/<uid>.<ext>` (последняя картинка; движок обновляет их раз в неделю).
- Отправляет только новое/изменённое (состояние `~/.cache/lives-to-r2.state`), данные движка только читает (`sudo cat`).
- Cron `40 0 * * *`, лог — тот же `~/journal-to-r2.log`. Первый прогон 30.10.2026: 5307 аватарок (21 МБ).
- Индекса (какой эфир, когда, сколько побед) пока нет — список объектов R2 по префиксу `lives/<комната>/`; таблица в DynamoDB — когда появится сервис для стримеров.
- Бесплатно до 10 ГБ в R2 (~0,85 ГБ/год).
